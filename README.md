# Trillium Flower Toy
This is my Trillium Flower project made with a group of other students.

## list of parts and quantities needed:

| Part Name | # to Print | Purpose |
| :--- | :--- | :--- |
| 2nd_shell_flower | x1 | tube used to keep body_stick_flower aligned vertically (prevents rotation of plunger relative to the _____) |
| Base(1) | x1 | Bottom of flower pot, it has ridges to make it easier to twist |
| Petal_pin | x3 | used to connect petal joints to the stem of the pot body |
| body_stick_flower | x1 | The inner plunger used to push the petal_joints up when the base is twisted |
| leaf | x3 | Decorative leaves that are inserted onto petal_joints |
| little_stick_flower | x1 | pin inserted into body_stick_flower to keep it in the tracks of 2nd_shell_flower and trial1_flower |
| pegs | x2 | Pegs used to attach the base to the pot_body |
| pedal_pins | x3 | pins used to attach the petal_joints to the stems in pot_body, they form a hinge connection |
| petal_joint | x3 | Hinge connections that have a lever arm for the body_stick_flower to push to rotate them, the leaves attach to them |
| trial1_flower | x1 | A shell over the 2nd_shell_flower with a helical track to push the little stick and body_stick_flower up when its rotated|
