# Trillium Flower Toy
This is a Trillium Flower Toy project made with a group of other students. The goal was to make a 3D printed puzzle that had a Canadian theme, we made a trillium flower in a pot that has a "blooming" affect when the base of the pot is twisted and could easily be assembled. 

## Assembly Video Link
https://youtu.be/r-UgOA_WQNQ

## Bill of Materials

| Part Name | # to Print | Purpose |
| :--- | :--- | :--- |
| pot_body | x1 | This is the shell of the whole trillium flower pot and has the flowers stem at the top |
| body_stick_flower | x1 | The inner plunger used to push the petal_joints up when the base is twisted |
| little stick | x1 | pin inserted into body_stick_flower to keep it in the tracks of 2nd_shell_flower and trial1_flower |
| 2nd_shell_flower | x1 | tube with a track in it for little stick, attached to the pot_body, used to keep body_stick_flower aligned vertically (prevents rotation of plunger relative to the pot body) |
| trial1_flower | x1 | A shell, attached to Base, over the 2nd_shell_flower with a helical track to push the little stick and body_stick_flower up when it's rotated |
| Base (1) | x1 | Bottom of flower pot, it has ridges to make it easier to twist |
| petaljoint | x3 | Hinge connections that have a lever arm for the body_stick_flower to push up to rotate them (this is the "blooming effect"), the flower petals (leaf) attach to them, connecting the petals to the stem |
| leaf | x3 | Decorative flower pedals that are inserted onto petal_joints |
| Pedal_pin | x3 | used to connect petal joints to the stem of the pot_body |
| pegs | x2 | Pegs used to attach the base to the pot_body |
